# Praveenkumar B - Data Analyst Portfolio

A modern, responsive React portfolio website showcasing professional experience, skills, and projects as a Data Analyst.

## Features

- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Modern UI**: Clean and professional interface with smooth animations
- **Sections Included**:
  - Hero section with call-to-action
  - About me
  - Skills and expertise
  - Featured projects
  - Professional experience
  - Contact form
  - Footer

## Tech Stack

- **Frontend Framework**: React 18
- **Build Tool**: Vite
- **Styling**: CSS3 with custom properties (variables)
- **Deployment Ready**: Optimized for production builds

## Prerequisites

- Node.js (v14 or higher)
- npm or yarn

## Installation

1. Navigate to the project directory:
```bash
cd praveenkumar-portfolio
```

2. Install dependencies:
```bash
npm install
```

## Development

Start the development server:
```bash
npm run dev
```

The application will be available at `http://localhost:5173`

## Building for Production

Create an optimized production build:
```bash
npm run build
```

Preview the production build:
```bash
npm run preview
```

## Customization

Edit the following files to customize your portfolio:

- **Header/Navigation**: Update links in `src/components/Header.jsx`
- **Skills**: Modify skill categories in `src/components/Skills.jsx`
- **Projects**: Add/edit projects in `src/components/Projects.jsx`
- **Experience**: Update work history in `src/components/Experience.jsx`
- **Contact**: Update contact details in `src/components/Contact.jsx`
- **Styling**: Customize colors via CSS variables in `src/index.css`

## Color Theme

The portfolio uses the following color scheme (in `src/index.css`):
- Primary Color: `#2563eb` (Blue)
- Secondary Color: `#1e40af` (Dark Blue)
- Text Color: `#1f2937` (Dark Gray)
- Light Text: `#6b7280` (Gray)
- Background: `#ffffff` (White)
